# Kit Claude Code — Hydrotic CI (phase 1 : interface)

## Utilisation
1. Copiez ce dossier comme racine de votre dépôt (ex. `hydrotic-ci/`).
2. Ouvrez un terminal dans ce dossier et lancez `claude`.
3. Premier message à envoyer :

> Lis CLAUDE.md, docs/SPEC_UI.md et design/tokens.json. Commence l'étape 1 de la section 7 (initialisation), puis arrête-toi et montre-moi le résultat.

Ensuite, validez chaque étape avant de passer à la suivante (« Étape validée, passe à l'étape 2 »).

## Contenu
- `CLAUDE.md` — règles, pile technique, ordre de travail, critères d'acceptation (lu automatiquement par Claude Code).
- `docs/SPEC_UI.md` — détail de chaque écran (mobile M0 à M7, tableau de bord D1 à D8, mode démo).
- `design/tokens.json` — couleurs, typographies, rayons, tailles.
- `design/reference/` — captures, prototype HTML/CSS (à ouvrir dans un navigateur), 4 vidéos de démonstration.
- `fixtures/` — données fictives JSON.
- `assets/` — logos Hydrotic CI.
- `docs/` — cahier des charges v3.0 (PDF) et diagrammes UML.

Prérequis sur votre ordinateur : Flutter (stable), Node.js 18 ou plus, un émulateur Android ou un téléphone.
